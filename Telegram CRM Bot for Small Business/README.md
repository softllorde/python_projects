# Telegram CRM Bot

## Description
Telegram bot for small businesses to manage client base directly from chat.

## Features
- User registration
- Role-based access (Admin / User)
- Client management (CRUD)
- Status tracking
- Duplicate protection

## Tech Stack
- Python
- Aiogram
- SQLAlchemy (async)
- SQLite

## Use Case
Small businesses that handle clients via messengers (services, freelancers, shops).

## Commands
/add_client  
/clients  
/set_status  
/delete_client
